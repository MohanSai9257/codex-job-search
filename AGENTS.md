# Job search project

This is a local React/Vite + Express + SQLite dashboard. Run commands from this directory. Read `DEVELOPMENT_PROGRESS.md` for implementation state and `skill/job-search/SKILL.md` for user commands. `data/jobs.sqlite` is durable state; never delete it during ordinary search or recovery. Resume from the database with `npm run cli -- CONTINUE`. Use `npm run cli -- STATUS` first. Company order is frozen per run. Public board adapters currently cover Greenhouse, Lever, and SmartRecruiters; unsupported boards fail visibly. The UI uses localhost ports 5173 and 4317. Run `npm run dev` to launch. Resume and job descriptions may be processed by Codex's model service when analyzed in Codex. No automatic applications or resume uploads to career sites.
